## Codebase Patterns

### Static HTML at project root
- **Where**: `planets.html` (root)
- **Pattern**: Zero-dependency static HTML with inline `<style>` block only. No `<script>` tags. Place at project root, never under `src/`.
- **Example**: `<article class="planet-card">...</article>` with `<dl>` for facts.
